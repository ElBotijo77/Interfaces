# 01 - Hello JSX

Primer proyecto con React y JSX, creado con Vite.

## Tecnologías

`Vite` `React` `Tailwind CSS` `shadcn/ui`

## Despliegue

Desde la carpeta del proyecto, instala las dependencias:

```bash
npm install
```

Y arranca el servidor de desarrollo:

```bash
npm run dev
```

La aplicación estará disponible en la URL que muestre la terminal (por defecto, `http://localhost:5173`).
